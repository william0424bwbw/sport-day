# 運動會賽程系統 使用說明（老師版）

2026-11-15

用手機或電腦打開網址，就能隨時查看運動會每一項比賽的時間、檢錄時間、場地和道次表；賽程有修改時，畫面會在幾秒內自動更新，不用重新整理。

## 1. 打開網址

請依你的身分，點下面對應的連結。第一次打開後，這台手機會記住你的身分，之後直接打開網址就好。

| 身分 | 連結 | 看得到的內容 |
| --- | --- | --- |
| 班級導師 | [導師專用連結](https://sport-day.teacherbear.workers.dev/?role=teacher) | 比賽時間、檢錄時間、場地、裁判、道次表 |
| 工作人員、裁判 | [工作人員專用連結](https://sport-day.teacherbear.workers.dev/?role=staff) | 導師看得到的全部，再加上器材、志工與公差、細流表 |

- 手機、平板、電腦都可以用，不需要帳號、不用安裝任何 App。
- 兩種身分都只能看，不能修改賽程；賽程由體育組統一編排。
- 拿錯連結也沒關係，可以在「設定」分頁切換身分。

## 2. 加到手機主畫面（建議）

加到主畫面後，會多一個藍底、白色跑道加黃旗的「運動會賽程」圖示，點一下就能全螢幕開啟，沒有網路時也能打開。

**iPhone（請用 Safari 打開連結）**

1. 用 Safari 打開上面的連結。
2. 點畫面下方的「分享」按鈕（方框加向上箭頭）。
3. 往下滑，點「加入主畫面」，再點右上角「加入」。

**Android（Chrome）**

1. 用 Chrome 打開上面的連結。
2. 點右上角「⋮」。
3. 點「安裝應用程式」或「加到主螢幕」。

從 LINE 點開連結時，會先在 LINE 內建瀏覽器打開，無法加到主畫面。請先點右上角選單，選「以預設瀏覽器開啟」，再照上面的步驟操作。

## 3. 手機畫面導覽

手機畫面最下方有四個分頁，最上方是比賽日切換與同步狀態。

| 分頁 | 你會看到 | 什麼時候用 |
| --- | --- | --- |
| 今日 | 「進行中」的比賽，和「下一項」還有幾分鐘檢錄 | 比賽當天最常用，一打開就知道現在輪到什麼 |
| 賽程 | 當天所有項目，依時間排列，標示未開始／檢錄中／進行中／已結束 | 找自己班級或自己負責的項目 |
| 場地 | 單一場地從 07:00 到 17:00 的時間軸 | 想知道某個場地一整天的安排 |
| 設定 | 切換身分、查看同步狀態；工作人員另有細流表 | 拿錯身分連結或要列印細流表時 |

畫面上方的綠點「即時同步」表示賽程是最新的；體育組一改時間，你的畫面會自動跟著更新。

用電腦或橫放的平板開啟時，會看到「時間 × 場地」的大表格，內容與手機相同，點任一個賽程方塊就能看細節。

## 4. 找到自己的項目

先選對比賽日，再用篩選只留下和你有關的賽程。

1. **選比賽日**：點畫面最上方的日期，例如「12/19（六）運動會正式賽」。平常日子打開時，「今日」可能是空白的，切到比賽日就看得到。
2. **打開篩選**：到「賽程」分頁，點「篩選」。
3. **導師**：點你的年級（一年級到六年級、特教班、全校／親師），只會留下該年級的項目。
4. **工作人員、裁判**：在搜尋框輸入你的名字、職務（例如「發令」）或項目名稱，或直接點下方列出的老師名字。
5. 也可以用「場地」下拉選單，只看某一個場地。

篩選後要看回全部賽程，點「清除」就好。

## 5. 賽程細節

點任何一張賽程卡片，下方會滑出這個項目的完整資料；往下滑或點右上角「×」關閉。

| 欄位 | 說明 | 導師 | 工作人員 |
| --- | --- | --- | --- |
| 比賽時間 | 正式開始與結束時間 | 看得到 | 看得到 |
| 檢錄時間 | 選手要提早到檢錄區的時間，例如「08:40 檢錄（提早 20 分）」 | 看得到 | 看得到 |
| 場地 | 比賽地點，可能同時使用多個場地 | 看得到 | 看得到 |
| 道次表／選手名單 | 體育組上傳的圖片或 PDF，點一下放大 | 看得到 | 看得到 |
| 道次備註 | 例如「第 1 道紅、第 2 道黃」 | 看得到 | 看得到 |
| 裁判分工 | 每位老師負責的職務 | 看得到 | 看得到 |
| 器材 | 需要準備的器材 | 看不到 | 看得到 |
| 志工與公差 | 人數與任務 | 看不到 | 看得到 |

如果檢錄時間出現黃色提醒，表示檢錄時段和同場地的前一項比賽重疊，請讓選手在場邊等候。

## 6. 細流表（工作人員）

工作人員可以把賽程印成公文格式的「賽務工作細流表」，或下載成 Excel 檔。

1. 手機：到「設定」分頁，點「細流表（列印 / CSV）」。電腦：點畫面右上方的「輸出細流表」。
2. 選「僅看本日」或「全部日期」。
3. 點「列印／另存 PDF」：印出 A4 直式，每個比賽日一頁；在列印畫面選「另存為 PDF」就能存成檔案。
4. 點「匯出 Excel（.csv）」：下載的檔案用 Excel 開啟，中文不會亂碼。

細流表的內容和系統上的賽程同步；賽程改了之後，請重新列印一份。

## 7. 沒有網路、出現「有新版本」時

**操場上沒有網路**：只要這支手機之前打開過一次，沒有網路時也能開啟，會顯示上次同步的賽程，上方標示「離線」。離線時看不到體育組剛改的時間；網路恢復後會自動更新。比賽當天早上出門前，建議先用有網路的地方打開一次。

**畫面下方出現「有新版本可以使用」**：這是系統本身有更新，不是賽程改了。點「更新」後畫面會重新整理一次；正在忙的話可以先點「稍後」。

## 8. 常見問題

**「今日」是空白的？** 今天不是比賽日，或還沒選到正確的日期。點最上方的日期切換，或到「賽程」分頁查看。

**找不到自己班的項目？** 先確認日期選對，再檢查是不是開著其他篩選，點「清除」後重新選年級。

**看不到器材、志工與公差？** 導師身分預設不顯示這些內容。如果你也負責賽務工作，請改用工作人員連結，或在「設定」切換成「工作人員」。

**畫面上的時間和廣播不一樣？** 以現場廣播和司令台為準。確認上方是「即時同步」而不是「離線」；離線時看到的是較舊的賽程。

**系統目前還在試用階段**，賽程內容可能還會調整。發現問題或有建議，請聯絡體育組 楊合萍老師。系統「設定」分頁最上方也會顯示目前的聯絡窗口。
