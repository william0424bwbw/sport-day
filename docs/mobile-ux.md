# 手機版畫面規格

- 寬度 360–430px；不可出現水平捲動（格狀表除外，且只在電腦版）。
- 按鈕、可點擊區域至少 44 × 44px。
- 頂部與底部固定列需加上 `env(safe-area-inset-*)`。
- 任何浮動元素都不可遮住主要內容；彈出內容一律用「底部滑出面板」或「全螢幕表單」，可用返回鍵／下滑關閉。
- 斷點：`< 1024px` 用手機排版，`≥ 1024px` 用電腦排版（平板直向也用手機排版）。

## 賽程（列表）
- 依開始時間排序的卡片；每張顯示時間、檢錄時間、場地、標題、狀態（未開始／進行中／已結束）。
- 上方篩選晶片：年級、場地、人員搜尋。
- 點卡片 → 底部滑出「賽程細節」：裁判、器材、志工、公差、備註、道次表。
- 管理者在細節面板有「編輯」「複製」「刪除」與現場調度按鈕。

## 場地（單一場地時間軸）
- 上方選場地；下方是 07:00–17:00 的直向時間軸（只有一欄，夠寬）。
- 管理者：長按卡片拖曳移動、拖曳上下邊緣調整長度；點空白處新增。

## 設定
- 角色切換、管理者密碼、專案代碼、同步狀態。
- 管理者：場地管理、比賽日管理、司令台時段、模擬時間、匯出入（I8）。

## 表單（管理者，全螢幕）
- 賽程表單：標題、顏色、日期、開始／結束時間、檢錄提早分鐘、磁吸連動、場地（多選）、裁判（多列）、器材（預設 + 自訂）、志工、公差、備註、附件（相機）。
- 儲存在底部固定列，不會被鍵盤擋住。
